What the product does

4Speach recognises speech, translates it and voices it — in both directions, on top of any calling application. The translation is machine translation.

Machine translation makes mistakes. It helps you hold a conversation, but it does not replace a professional interpreter where the cost of an error is high: signing contracts, court, a medical diagnosis. For those cases the program window shows subtitles with the original — a doubtful phrase can always be reread and queried.
